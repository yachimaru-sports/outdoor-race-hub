# OUTDOOR RACE HUB 専用 Geminiスキル設定ガイド

Geminiの「スキル」作成画面（添付画像で開いていただいた画面）で、本スキルを登録する手順です。

---

## 📁 フォルダ内のファイル構成
- **`SKILL.md`**: スキルの詳細設計書・調査ルール・出力フォーマット
- **`INSTRUCTIONS.md`**: Geminiの「カスタム指示」欄にそのまま貼り付けるプロンプト
- **`outdoor_race_hub_events_master.csv`**: 全147大会のマスターデータ（Googleスプレッドシートにインポート用）

---

## 🚀 Geminiスキル登録手順（3ステップ）

### ステップ1：Geminiの「スキル」を新規作成
1. ブラウザで [Google Gemini スキル画面](https://gemini.google.com/customize/skills) を開く
2. 右上の **「作成 ▼」** をクリック

### ステップ2：基本情報とカスタム指示を設定
- **名前**: `OUTDOOR RACE HUB 大会調査エージェント`
- **説明**: `全国＆中四国のアウトドア・トレラン・アドベンチャー・サイクリング大会を調査し、Googleスプレッドシートに追記する専用スキル`
- **ファイル（添付）**:
  - `SKILL.md` をアップロード
- **カスタム指示**:
  - `INSTRUCTIONS.md` の中身をコピーして、そのまま貼り付け

### ステップ3：Googleスプレッドシートを準備
1. Googleドライブで新規「Googleスプレッドシート」を作成（名前: `OUTDOOR RACE HUB 大会マスター`）
2. 「ファイル」→「インポート」から `outdoor_race_hub_events_master.csv` をアップロード
3. これで全147大会がスプレッドシートに展開されます！

---

## ⏰ スケジュール自動実行（PC電源OFFでも稼働）
1. Geminiの左メニューにある **「スケジュール設定済み」** を開く
2. 「新しいスケジュール」を作成し、上記スキルを指定
3. プロンプト例：
   ```
   全国および中四国のトレイルランニング、アドベンチャーレース、ロングライドの新着大会（2026年〜2027年開催）を調査し、公式URL・エントリーURL・必携装備を含めてスプレッドシートの形式で出力してください。
   ```
4. 実行頻度（例: 毎日午前8時）を設定して完了！
