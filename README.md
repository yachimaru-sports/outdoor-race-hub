# OUTDOOR RACE HUB ⚡

アウトドア・エンデュランス競技（トレイルランニング、アドベンチャーレース、長距離サイクリング、マラソン）の大会情報集約ダッシュボード、および楽天アフィリエイト連動の特価ギア速報ポータルサイトです。

GitHub Pages による完全無料の SPA（Single Page Application）静的ホスティングに対応しています。

---

## 🌟 主な機能と特徴

1. **⚡ 楽天アフィリエイト連動 特価・高還元ギア速報ティッカー**
   - 画面最上部に常駐するタイムセール＆高還元ギアの横スクロールカルーセル。
   - 割引率や楽天ポイント倍率（P15倍、P20倍等）をリアルタイムにバッジ表示。

2. **📌 マイプリセット保存機能（`localStorage` 活用）**
   - 絞り込み条件（種別、地域、距離レンジ、ステータス、キーワード）とソート状態に名前をつけて保存可能。
   - 上部のタグからワンクリックで呼び出し・復元・個別削除が可能。
   - デフォルトで「中国地方トレラン」「全国100km+ウルトラ」「エントリー受付中のみ」等の実用プリセットを内包。

3. **🎛️ 多次元フィルター & リアルタイムソート**
   - **競技種別:** トレイル / アドベンチャー / サイクリング / マラソン
   - **地域・都道府県:** 中国地方（広島・岡山・山口・鳥取・島根）から全国主要エリアまで即時フィルター
   - **距離レンジスライダー:** 0km 〜 200km+
   - **ステータス:** 受付中（緑）/ 締切間近（赤パルス）/ 告知中（青）/ 終了（グレー）
   - **ソート:** 開催日昇順/降順、距離順、累積標高順、レビュー高評価順

4. **🔄 ハイブリッド表示（テーブルビュー vs カードビュー）**
   - **コンパクトテーブルビュー:** 一覧性・視認性を極限まで高めたデータシート形式。
   - **カードビュー:** 必携装備タグやレビュー評価、獲得標高メーターが整理されたグリッド形式。

5. **🎒 持ち物チェックリスト & 特価ギア提案モーダル**
   - 大会をクリックすると詳細モーダルが起動。
   - **必携品チェックリスト:** 各装備のチェック状態を `localStorage` に保存。次回アクセス時も準備状況が維持されます。
   - **特価ギア連動提案:** その大会の必携品カテゴリ（ウェア、ライト、補給食、エイド、ナビゲーション等）に合致する楽天特価セール品を自動レコメンド。

## 🛠️ 技術スタック

- **フロントエンド:** React 18, TypeScript, Vite
- **スタイリング:** Tailwind CSS (アウトドア・テック系ダークモード、エメラルド＆アンバー基調)
- **アイコン:** `lucide-react`
- **データ管理:** ローカル JSON (`events.json`, `deals.json`) + `localStorage`
- **デプロイ環境:** GitHub Pages (`.github/workflows/deploy.yml` による自動CI/CD)

---

## 🚀 ローカルでの起動手順

Node.js がインストールされている環境で、以下のコマンドを実行してください。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:5173/` を開くと動作を確認できます。

### プロダクションビルドの確認
```bash
npm run build
npm run preview
```

---

## 🌐 GitHub Pages へのデプロイ手順

1. 本リポジトリを GitHub にプッシュします。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Source** で `GitHub Actions` を選択します。
4. `main` ブランチにプッシュされると、`.github/workflows/deploy.yml` が自動起動し、数分でサイトが公開されます。
   （※ SPAフォールバックとして `dist/404.html` が自動生成されるため、リロード時も404エラーになりません）
